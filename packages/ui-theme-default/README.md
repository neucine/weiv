# @weivjs/ui-theme-default

Default design token theme for Weiv UI.

## Purpose

This package defines token variables and starter component styles.

- behavior lives in `@weivjs/ui-core`
- visual design lives here

## Install

```bash
npm i @weivjs/ui-core @weivjs/ui-theme-default
```

## Usage

```js
import "@weivjs/ui-theme-default/tokens.css";
import "@weivjs/ui-theme-default/components.css";
```

Apply a theme root:

```html
<div data-theme="default">...</div>
```
